# prototype/

SPEC's preamble refers to a single-file prototype at
`prototype/weeds-of-melbourne-prototype.html`, to be used as a design and
interaction reference.

**That file was not present in the repository when this build was done.** The
layout, routing model, design tokens (SPEC §9) and gallery behaviour (SPEC §8)
were implemented from the spec text directly.

If the prototype turns up, drop it in here. It is reference only — nothing in
this directory is built or published.
